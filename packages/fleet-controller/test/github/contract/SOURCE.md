`openapi.subset.json` is that description reduced to the operations and

reference. Documentation keys (`description`, `summary`, `example(s)`,
`externalDocs`, `x-github`, `title`, `deprecated`) are removed; every keyword
that changes what is valid is kept verbatim.

## Refresh

From `packages/fleet-controller`, with the new commit of
`github/rest-api-description` (the contract tests never touch the network):

```sh
bun run scripts/refresh-github-openapi.ts <40-hex commit sha>
bun test test/github/contract
```

The script downloads the file from raw.githubusercontent.com at that commit with
no credentials. Pass `--file <local copy>` to work offline. The output depends
only on the commit and `selection.ts`, so the same commit always gives the same
bytes. A failing contract test after a bump means GitHub changed what a client
or the fakes must send or return.
